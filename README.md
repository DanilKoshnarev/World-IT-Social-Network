# World IT Social Network

## Про проект 🚀
World IT Social Network - це соціальна мережа для IT-спеціалістів, яка дозволяє розробникам зі всього світу спілкуватися, ділитися досвідом та знаходити нові можливості для співпраці.

## Технології 💻
- React
- TypeScript
- Node.js
- Express
- MongoDB
- Redux Toolkit

## Встановлення 🛠
1. Склонуйте репозиторій:
```bash
git clone https://github.com/DanilKoshnarev/World-IT-Social-Network.git
```

2. Встановіть залежності:
```bash
cd World-IT-Social-Network
npm install
```

3. Запустіть проект:
```bash
npm start
```

## Функціонал 🔥
- Авторизація та реєстрація користувачів
- Створення профілю розробника
- Публікація постів та коментарів
- Спілкування в чаті
- Пошук розробників за навичками
- Можливість створення груп за інтересами
